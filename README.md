# CodeAlpha Stock Portfolio Tracker

A console-based portfolio calculator using a hardcoded dictionary of example prices.

## Features
- Accepts a supported stock symbol and quantity.
- Calculates per-stock and total estimated values.
- Can save a summary to `portfolio.txt`.

## Important
Prices are hardcoded examples for programming practice, not live or investment-grade market data.

## Run
```bash
python stock_portfolio_tracker.py
```

## Concepts practiced
Dictionaries, loops, input validation, arithmetic, functions, and file handling.
